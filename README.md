# 小芽成长

一个原创、完全离线的儿童日常表现考核 PWA。数据仅保存在 iPhone 的 Safari 浏览器内。

## 已实现

- 自定义考核项目与分类
- 每日「做得很棒 / 基本完成 / 需要提醒」评分（+5 / +2 / −2 分）
- 积分累计与明细、每日文字记录
- 心愿奖励兑换
- 周统计、连续达标天数和月历
- JSON 导入/导出备份
- Service Worker 离线缓存

## iPhone 安装

1. 将整个 `baby-growth` 文件夹发布到任意 HTTPS 静态网站服务（例如 GitHub Pages、Cloudflare Pages 或 Netlify）。
2. 在 iPhone Safari 打开该网址，等待页面完整加载一次。
3. 点击 Safari 的「分享」按钮，选择「添加到主屏幕」。
4. 以后从主屏幕打开，即使没有网络也可以使用。

首次安装和数据导入前，建议在「成长记录」页导出一份备份。Safari 的「清除网站数据」会删除本机数据。
